## 一、产品定义

### 1.1 一句话定义

> **Moodmold 是一个让城市宠物在屏南乡村被照顾、被记录、被讲述的"乡村寄养合作平台"——以"有福"为代言的真实村猫 IP 串联起寄养业务、数字孪生体验和屏南文旅宣传，让寄养不只是一次托管，而是一段乡村陪伴的故事。**

### 1.2 三大业务模块（与你的任务书对齐）

```
┌────────────────────────────────────────────────┐
│  模块 1：管理宠物寄养                            │
│  对象：屏南乡村民宿/养宠村民                     │
│  内容：标准制定 + 准入准出 + 培训赋能 + SaaS 工具│
│  收入：平台抽佣（每笔订单 20%）                  │
└────────────────────────────────────────────────┘
┌────────────────────────────────────────────────┐
│  模块 2：沟通宠物家长                            │
│  对象：城市宠主                                  │
│  内容：数字孪生身份 + 日报 + 闪闪时刻 + 解锁卡片 │
│  收入：寄养服务客单（150-200 元/天）             │
└────────────────────────────────────────────────┘
┌────────────────────────────────────────────────┐
│  模块 3：宣传寄养业务（附产品自动生成）           │
│  对象：屏南文旅 / 社交平台                       │
│  内容：以宠物视角生成内容 + 有福 IP 包装          │
│  收入：无主动运营，作为获客和品牌资产             │
└────────────────────────────────────────────────┘
```

### 1.3 商业模型（沿用你的选择：交易抽佣）

```
宠主支付：150 元/天 × 7 天 = 1,050 元

  ├─ 民宿主：60% = 630 元（民宿净增收）
  ├─ 平台佣金：20% = 210 元
  ├─ 硬件挂牌摊销：35 元
  ├─ AI 内容生成成本：70 元
  ├─ 保险池：50 元
  └─ 平台运营：55 元
```

**为什么坚持抽佣**：你保留"参与平台抽佣"的判断是合理的——SaaS 订阅在初期民宿基数太小（10-50 家），收不上钱；抽佣随业务量自然增长，符合早期平台融资叙事。

## 三、"旅行青蛙模式"产品机制设计

> 你选择的是 **混合策略：日报 + 不定时闪闪时刻**——这是产品最具差异化的设计。

### 3.1 双层结构

```
底层：每日日报（安心层）
  ├─ 早 9:00  早安推送（吃饭情况）
  ├─ 中 13:00 午间状态（活动/休息）
  └─ 晚 19:00 一日总结（精神状态 + AI 故事）
  └─ 触发：民宿老板手动提交，自动模板生成

上层：闪闪时刻（惊喜层）
  ├─ 不定时触发（每日 0-2 次随机）
  ├─ 由"有福"以东道主视角发送
  ├─ 内容：今日和客猫的偶遇 / 古村漫步 / 非遗变装合影
  └─ 触发：民宿老板拍到特别瞬间时主动上传 / 或系统按"剧情节点"自动推送
```

### 3.2 闪闪时刻的"剧情节点"（演示用）

| 寄养日 | 闪闪时刻内容 | 用户情感目标 |
|---|---|---|
| Day 1 | 有福迎接客猫 → "今天又来了个城里客人" | 入营仪式感 |
| Day 3 | 客猫第一次摸到廊桥 → 非遗变装解锁 | 第一次惊喜 |
| Day 5 | 客猫和有福在院子里晒太阳合影 | 关系建立 |
| Day 7 | 有福送别客猫 → "城里人要走了，我又是一个人了" | 离别情感峰值 |

**演示中可以浓缩到 90 秒内呈现 Day 1、3、5、7 各一个闪闪时刻**——这是最有冲击力的情感曲线。

### 3.3 解锁机制（你的任务书 2c + 2d）

```
寄养第 1 天 → 解锁"屏南通行证"基础身份卡
寄养第 3 天 → 解锁"廊桥小斗笠"非遗装扮
寄养第 5 天 → 解锁"龙潭古厝"戏服装扮
寄养第 7 天 → 解锁"屏南荣誉村猫"纪念卡（终极）
寄养结束 → 整套数字身份卡 + 7 天日记打包送给宠主
```

**机制本质**：寄养时间 = 解锁度 = 收藏价值 = 复购动力。

## 四、村民准入准出机制

### 4.1 准入流程（5 步）

```
1. 民宿主报名 → 提交资料（民宿照片、营业执照、养宠经验）
2. 平台远程审核 → 视频核查环境、查看是否符合 V2.0 标准
3. 实地认证（首批由 Moodmold 团队上门）→ 颁发"屏南乡村寄养认证民宿"挂牌
4. 平台培训（线上半天）→ 教使用民宿端 H5 + 拍照规范 + 应急流程
5. 试运营 1 个月 → 接 3 单试养，宠主评分 ≥ 4.5 星可正式入驻
```

### 4.2 准出机制（违约处理）

| 等级 | 触发条件 | 处理 |
|---|---|---|
| 黄牌警告 | 单次评分 < 3 星 / 漏发日报 ≥ 2 次/单 | 平台沟通整改，再犯升级 |
| 红牌停业 | 宠物受伤、走失、健康问题 | 暂停接单，平台调查 |
| 永久退出 | 宠物死亡、严重虐待证据、保险欺诈 | 撤销认证，平台公示 |

### 4.3 屏南乡村寄养环境标准 V2.0（关键升级）

#### 硬件（一票否决项）

- 独立寄养房间 ≥ 6㎡（不与游客住房混用）
- 房间可关闭门窗（防逃逸）
- 防滑地面 + 易清洁
- 食盆、水盆、猫砂盆各 1 套
- 室内温控（空调或风扇）
- 应急联系电话 24 小时可达

#### 服务

- 每日 2 次喂食（定时）
- 每日 3 张照片上传
- 每日健康状态打卡（吃饭/排泄/精神）
- 异常 1 小时内联系宠主
- 不与其他宠物混养（除非同主人）

#### 屏南特色加分项

- 院落或户外空间
- 30 分钟车程内有非遗景点
- 民宿主有 1 年以上养宠经验
- 提供宠物迎接/送回服务
- **拥有"有福"这样的村猫作为同伴**（独家）

## 十、核心战略侧重点

按重要性排序：

### 第 1 位：有福 IP 的真实性

**所有视觉、文案、演示都围绕有福**：
- 它真实存在
- 它有名字、有故事、有照片
- 评委一眼看出"这是真的"

### 第 2 位：在地伙伴的现身说法

**民宿老板的真实性是无价的**：
- 他真的养有福
- 他真的开民宿
- 他真的有寄养能力
- 这是你对所有 PPT 创业队的降维打击

### 第 3 位：闪闪时刻的情感峰值

**这是和竞品最大的差异**：
- 别人给你数据
- 我们给你故事
- 别人给你 7 天 21 次 checklist
- 我们给你 7 天 7 个值得分享的瞬间

### 不要陷入的"技术陷阱"

❌ 不要试图证明"我们的 AI 多牛"  
❌ 不要试图证明"我们的项圈多智能"  
❌ 不要试图证明"我们能服务多少民宿"

✅ 要证明"有福是真的"  
✅ 要证明"乡村寄养是真的能做的"  
✅ 要证明"我们三个人是认真的"
