# Part 1 — 宠主寄养服务质量保证体系

> 讲述逻辑：硬件切入 → 服务流程 → 质量数据
> 物证锚点：智能项圈实物（3D 打印模型）

## P1-1 从"看不见"到"全透明"

| 讲了什么 | PPT 上放什么 |
|---------|------------|
| 宠物主最大痛点：寄养后不知道宠物在干嘛 | 三个 emoji：❓ 它吃了吗 / 😰 它被关了吗 / 📱 谁来告诉我 |
| Moodmold 的回答：一个有硬件+软件+内容的三层体系 | 三层结构图：项圈(感知层) → 平台(数据层) → 日记/通行证(体验层) |

## P1-2 挂牌 + 项圈：双重身份保障

| 讲了什么 | PPT 上放什么 |
|---------|------------|
| 挂牌（tagId）：物理标识，扫码绑定数字身份，低门槛冷启动 | 挂牌实物照片 + 二维码指向宠主端 |
| 智能项圈：GPS 定位 + 体温监测 + 活动追踪，7×24 不间断 | 项圈 3D 渲染图 + 六大传感器图标卡片 |
| 为什么是双保险？挂牌解决"这是谁的猫"，项圈解决"猫在干嘛" | 二合一对比示意图 |

**项圈硬件 6 大功能速览**（一页展示）

| 功能 | 技术 | 宠主可见 |
|------|------|---------|
| GPS 实时定位 | 北斗+GPS 双模 | 当前位置 + 电子围栏 |
| 体温健康 | 红外 MLX90614 | 体温曲线 + 异常推送 |
| 活动追踪 | MPU6050 六轴 | 每日步数 + 活跃时段 |
| 环境感知 | 光照传感器 | 室内/室外标签 |
| 佩戴安全 | 双路压力传感器 | 松脱告警 |
| 本地交互 | OLED + LED + 蜂鸣 | 托管方可快速查看 |

## P1-3 服务流程：从预约到接回，全链路透明

```
扫码绑定 → 每日打卡 → 数字孪生日报 → 寄养纪念卡 → 接回评价
   ↓           ↓            ↓             ↓          ↓
 30 秒完成    托管方拍照      AI 自动出图    自动生成     五星好评
 挂牌关联     写一句话        推送宠主                      体系闭环
```

## P1-4 数字孪生日报：宠主端的"每日快乐"

| 讲了什么 | PPT 上放什么 |
|---------|------------|
| 不是冷冰冰的状态通知，是"有福视角"的第一人称日记 | 手机界面截图：DiaryListPage（3 篇日记列表） |
| 每一篇日记 = 照片 + 短文 + 非遗挂件出图 | 单篇日记放大：Day3 廊桥日记 + Day3Illustration SVG |
| 贯穿寄养全程，寄养结束后自动生成纪念卡 | 纪念卡片截图 |

## P1-5 实时推送：民宿端一动，宠主端就知道了

| 讲了什么 | PPT 上放什么 |
|---------|------------|
| 托管方拍照提交 → 3 秒内宠主端自动出现新日记 | 两个手机界面并列：左=托管方提交 / 右=宠主端弹出新日记 Toast |
| 这就是寄养信任建立的"魔法时刻" | 呼吸绿点动画截图 |

## P1-6 数据面板（量化信心）

| 指标 | 数据 |
|------|------|
| 信息透明度提升 | 托管方每日至少 2 次打卡 → 宠主可见频次 2×/天 |
| 异常响应速度 | 体温/定位告警 → 3 秒内双向通知 |
| 用户满意度预期 | 寄养全程可视化 → NPS 目标 ≥60 |
| 项圈量产成本 | BOM ¥235/件，零售 ¥399-499 |

# Part 2 — 村民寄养环境质量控制方案

> 讲述逻辑：选址 → 标准 → 培训 → 监督
> 物证锚点：屏南龙潭村民宿实地照片

## P2-1 不是谁都能做寄养

| 讲了什么 | PPT 上放什么 |
|---------|------------|
| Moodmold 定位：规范者，不是运营者 | 一句话大字："我们制定标准，村民执行标准，宠主验证标准" |
| 村民准入三道门槛：环境 → 培训 → 持续监督 | 三道门槛卡片 |

## P2-2 寄养环境准入标准

| 维度 | 具体要求 | 检查方式 |
|------|---------|---------|
| 空间 | 独立宠物活动区 ≥ 5m²，通风采光良好 | 实地拍照上传 |
| 安全 | 封窗/围墙，无危险物品，无有毒植物 | 清单逐项打勾 |
| 卫生 | 每日消毒 + 粪便清理SOP | 托管方后台打卡 |
| 温度 | 室内 18-28°C，极端天气有预案 | 项圈环境传感器 |

## P2-3 托管方培训体系

```
Day 0: 准入审核（环境照片 + 面谈）
   ↓
Day 1: 线上培训（宠物护理 SOP + 平台操作 + 摄影技巧）
   ↓
Day 7: 试用期（接第一只宠物，全程导师远程支持）
   ↓
Day 30: 正式评级（宠主评分 + 平台抽检 → 金牌/银牌/铜牌）
```

## P2-4 卫生与安全 SOP

| 事项 | 频率 | 记录方式 |
|------|------|---------|
| 活动区消毒 | 每日 1 次 | 托管方拍照打卡 |
| 食盆/水盆清洗 | 每餐后 | 打卡记录 |
| 猫砂/排泄物清理 | 每日至少早晚 2 次 | 打卡记录 |
| 宠物身体检查 | 每日 1 次 | 项圈数据 + 照片 |
| 异常上报 | 即时 | 一键告警 → 平台 + 宠主 |

# Part 3 — 基于数字孪生的宣传策略

> 讲述逻辑：形象 → 内容 → 传播 → 增长
> 物证锚点：有福 IP + 日记截图 + 通行证截图

## P3-1 数字孪生不是噱头，是传播引擎

| 讲了什么 | PPT 上放什么 |
|---------|------------|
| 传统宠物寄养 = 看不见 → 不会分享 | 对比：传统寄养（0 分享）→ Moodmold（每天 1 条朋友圈素材） |
| 数字孪生 = 宠主每天收到的不是通知，是可分享的内容 | 屏南日记 = 有福视角的图+文，自带传播属性 |

## P3-2 "有福" — 本村猫 IP 形象

| 讲了什么 | PPT 上放什么 |
|---------|------------|
| 有福是谁？屏南龙潭村的本村猫，品牌的 IP 角色 | 有福 IP 形象图 / 设计稿 |
| 有福做什么？在每一篇日记里以"第一人称"叙述宠物的屏南生活 | 日记截图高亮"—— 有福"签名 |
| 为什么是有福？本地猫 = 在地性 = 真实感 = 信任背书 | 三大传播资产卡片 |

## P3-3 传播内容矩阵

```
┌────────────────────────────────────────────┐
│              三大内容资产                   │
├───────────────┬──────────────┬─────────────┤
│  屏南通行证     │   每日日记     │  寄养纪念卡   │
│  品牌入口页     │   社交素材     │  传播终点     │
│  "宠物拿到了    │  "今天有福      │  "一段值得     │
│   屏南身份证"   │   带豆豆去...   │   珍藏的回忆"  │
│  扫码即看       │  朋友圈9宫格    │  可打印/分享  │
└───────────────┴──────────────┴─────────────┘
```

## P3-4 非遗挂件 × 数字孪生出图

| 讲了什么 | PPT 上放什么 |
|---------|------------|
| 宠物照片叠加屏南非遗挂件（斗笠/廊桥/古厝/戏服） | 出图效果对比：原始照片 vs 叠加挂件后的出图 |
| 每一张出图 = 一张可分享的屏南文旅明信片 | 4 张非遗风格出图 |
| 宠主自发传播 → 屏南文旅曝光 → 获客飞轮 | 飞轮图：寄养→ 出片→ 分享→ 获客→ 更多寄养 |

## P3-5 传播渠道与数据目标

| 渠道 | 内容形式 | 预期效果 |
|------|---------|---------|
| 宠主朋友圈 | 日记截图 + 出图 | 每次寄养 = 7-30 条自然传播 |
| 小红书/抖音 | 有福探店 + 宠物Vlog | 话题 #屏南宠物旅行 |
| 宠物社群 | 寄养纪念卡 + 通行证 | 口碑裂变 |
| 线下民宿 | 挂牌扫码入口 | 场景触发 |

# 总结与展望

## 6 页总结

```
P 总结-1: 我们做了什么
  ✓ 前端 SPA 18 页全链路（预约→绑定→打卡→日记→纪念卡→ 通行证）
  ✓ 智能项圈硬件方案（6 大传感器 + BOM ¥235 成本评估）
  ✓ 数字孪生内容体系（有福 IP + 非遗出图 + 实时推送）
  ✓ 村民寄养标准框架（准入/培训/SOP/评级）

P 总结-2: 我们的差异化
  不是又一个宠物寄养平台 → 是"硬件+软件+内容"三位一体的寄养质量体系
  不是冷冰冰的状态监控 → 是拟人化数字孪生带来的情感连接
  不是平台自己运营 → 是赋能村民的模式创新

P 总结-3: 商业模式
  收入来源：
    · 寄养服务佣金（15-20%）
    · 智能项圈销售/租赁（¥399-499）
    · 数字孪生出片增值服务（非遗挂件包 ¥9.9/套）
    · 屏南文旅联名推广
  平台角色：规范 + 工具 + 内容，不直接运营寄养

P 总结-4: 发展路线图
  阶段 1 (2026 Q3)    挂牌试点    屏南 3-5 家民宿
  阶段 2 (2026 Q4)    项圈小批量  100 件试产
  阶段 3 (2027 Q1)    全国推广    加盟模式

P 总结-5: 团队与呼吁
  团队：A(设计+IP) + B(技术+硬件) + 在地合作伙伴
  我们需要：民宿试运营伙伴 / 硬件试产资金 / 传播渠道资源

P 总结-6: 结语
  大字屏：
  "让每一次寄养，都成为一次值得珍藏的旅程。
   让每一只宠物，都拥有自己的数字孪生。
   让屏南的猫和远方的人，通过一根挂牌、一个项圈、一串代码，彼此看见。"

  → 扫码体验 Demo: moodmold-pingnan.vercel.app
```
