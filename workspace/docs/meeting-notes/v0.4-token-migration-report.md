### 替换映射（摘要）

- `bg-gray-50` → `bg-primary-bg`
- `bg-white` → `bg-card-bg`
- `bg-gray-100` → `bg-accent-soft`
- `text-gray-900/800/700/600` → `text-text-primary`
- `text-gray-500/400` → `text-text-secondary`
- `text-gray-300` → `text-text-tertiary`
- `border-gray-200/300` → `border-border-light`
- `bg-gray-900`（按钮）→ `bg-accent-primary`
- `bg-blue-50` → `bg-accent-soft`；`text-blue-600` → `text-accent-primary`
- `bg-green-400` → `bg-accent-primary`
- `font-bold/font-semibold` → `font-serif`
- `rounded-2xl/rounded-xl`（卡片）→ `rounded-card`
- `rounded-xl`（输入框）→ `rounded-input`
- `rounded-xl`（按钮）→ `rounded-pill`
- `shadow-sm` → `shadow-soft`
- 主按钮统一：`h-[52px] flex items-center justify-center rounded-pill bg-accent-primary`
- disabled 按钮：`bg-border-light disabled:cursor-not-allowed`
- 输入框统一：`h-[52px] rounded-input border-border-light focus:border-accent-primary`
