# Moodmold 智能项圈 — 硬件功能清单

> 日期：2026-05-23 | 版本 v1.0

---

## 一句话定义

**Moodmold 智能项圈是一款面向寄养宠物的可穿戴定位+健康监测设备，让远方的宠物主能看见宠物的每一个时刻。**

---

## 核心功能（6 大模块）

### 1. 实时定位追踪

| 项目 | 内容 |
|------|------|
| 技术方案 | GPS + 北斗双模定位模组（ATGM336H） |
| 定位精度 | 3-5 米（无干扰环境） |
| 核心场景 | 宠主端查看宠物当前位置、托管方查看宠物是否在电子围栏内 |
| 辅助定位 | 双路压力传感器判断项圈是否移位（充气项圈项目已验证） |

定位数据通过 WiFi/BLE 上传至 Moodmold 云端，宠主端实时可查。

### 2. 体温健康监测

| 项目 | 内容 |
|------|------|
| 技术方案 | 非接触式红外温度传感器（MLX90614） |
| 精度 | ±0.1°C |
| 监测内容 | 实时体温、异常温度推送（发热/低体温告警） |
| 核心场景 | 寄养期间持续监测宠物健康，异常即时通知托管方和宠主 |

### 3. 活动量追踪

| 项目 | 内容 |
|------|------|
| 技术方案 | 六轴加速度计+陀螺仪（MPU6050） |
| 监测内容 | 计步、活动量统计、久坐/异常行为识别、跌倒检测 |
| 核心场景 | 宠主端日报展示"今日走了多少步""活跃时段分布" |

### 4. 环境感知

| 项目 | 内容 |
|------|------|
| 技术方案 | 光照传感器（GPIO PB10） |
| 监测内容 | 环境亮度判断、室内/室外场景切换、夜间低功耗休眠 |
| 核心场景 | 自动识别宠物当前在室内还是室外，配合活动数据生成场景标签（"午后在院子晒太阳"） |

### 5. 佩戴状态感知

| 项目 | 内容 |
|------|------|
| 技术方案 | 双路压力传感器（ADC1 CH2 + CH5） |
| 工作原理 | 压力差分 → 判断项圈松紧、是否移位 |
| 3 种模式 | 自动调位（闭环调整）、手动充气、安全急停 |
| 参考来源 | 充气项圈项目已验证（main.c + beng.c + Rheo.c） |

### 6. 本地交互

| 项目 | 内容 |
|------|------|
| 显示屏 | 0.96" OLED（I2C PA10/PA11），显示实时状态 |
| 指示灯 | LED 状态灯（PA6），多色表示不同工作状态 |
| 蜂鸣器 | 有源蜂鸣器（PB11），异常告警/寻宠响铃 |
| 按键 | 轻触按键（PB0），模式切换/手动触发 |

---

## 通信与数据

| 项目 | 内容 |
|------|------|
| 短距通信 | Bluetooth BLE（低功耗，手机绑定配对） |
| 长距通信 | WiFi（ESP32-C3-MINI，数据上传云端） |
| 数据同步 | 项圈 → Moodmold 云端 → 宠主端实时查看 |
| 离线缓存 | 无网络时本地存储，恢复连接后自动补传 |

---

## 电源与续航

| 项目 | 内容 |
|------|------|
| 电池 | 400mAh 锂聚合物，3.7V |
| 续航 | 7-14 天（正常使用）|
| 充电方案 | TP4056 充电管理 IC + 磁吸充电 |
| 低功耗 | 休眠模式 μA 级待机，光照传感器触发夜间低功耗 |

| 项目 | 内容 |
|------|------|
| 安全扣 | 可拆卸设计，宠物受困时自动脱落 |
| 材质 | 食品级硅胶 / 尼龙织带，无毒亲肤 |
| 防水 | IP67 全密封灌胶，雨天/水域环境正常运作 |
| 重量 | 整机 ≤60g，猫/小型犬无负担 |
| 适配 | 颈围 18-42cm 可调 |

## 一句话卖点（写进 PPT / Demo 用）

> **"挂牌确认身份，项圈感知生命。"**

挂牌让宠物主知道宠物在哪里寄养；项圈让宠物主看见宠物在做什么、是否健康、是否开心。
