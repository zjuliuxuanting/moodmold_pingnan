## 二、项圈硬件架构（PPT 核心内容）

### 2.1 主控方案

| 参数 | 内容 |
|------|------|
| **MCU 型号** | STM32F103Cx |
| **架构** | ARM Cortex-M3, 72MHz |
| **优势** | 成熟方案、低功耗、丰富外设、价格低 |
| **参考来源** | 充气项圈项目已验证 STM32F103 驱动 OLED/ADC/PWM/I2C/GPIO 全链路可用 |

### 2.2 传感器模块清单

| 序号 | 模块 | 功能 | 接口 | 采购来源 |
|------|------|------|------|---------|
| 1 | **压力传感器 ×2**（ADC 采集） | 检测项圈松紧、宠物颈部活动状态 | ADC1_CH2 (PA2) + ADC1_CH5 (PA5) | A25 健康监测项圈同款或替换 |
| 2 | **温度传感器** | 体温监测（非接触热敏/红外） | ADC 或 I2C | 需调研选型 |
| 3 | **光照传感器** | 环境亮度监测，辅助判断室内/室外 | GPIO 数字输入 (PB10) | 充气项圈已验证 |
| 4 | **GPS/定位模块** | 实时定位，电子围栏 | UART (串口) | 需额外调研（见 §2.3） |
| 5 | **加速度计/陀螺仪** | 活动量追踪，姿态识别 | I2C 或 SPI | 需调研选型（推荐 MPU6050） |

### 2.3 定位功能专项（充气项圈已验证方案）

```
充气项圈项目代码中的"位置判断"(WZPD)逻辑：

┌─────────────────────────────────────────────┐
│  双路压力传感器 (ADC CH2 + CH5)               │
│      ↓                                       │
│  Rheo_caiji2() → ADC1_CH2 → PA2             │
│  Rheo_caiji5() → ADC1_CH5 → PA5             │
│      ↓                                       │
│  阈值判断 (>1000 或 <1000)                     │
│      ↓                                       │
│  气泵 Beng_Open/Stop (PA1)                   │
│  阀门 Fa_Open/Stop   (PA4)                   │
│  电机 Motor_Set±    (PA6/PA7/PA3)            │
│      ↓                                       │
│  OLED 显示实时压力值                          │
│  (PA10-SCL, PA11-SDA, I2C, 0x78)            │
└─────────────────────────────────────────────┘

3种工作模式：
  模式0: 自动调位 — 压力驱动气泵/阀门，闭环调整位置
  模式1: 手动充气 — 按键 EXTI0 (PB0) 中断触发
  模式2: 安全急停 — 压力超限时自动停止

本黑客松项目可复用的定位逻辑：
  压力差分 → 判断项圈是否移位 → 触发警报或自动修正
```

## 四、A 可直接引用的关键数据

### 4.1 STM32F103 核心参数

- 主频：72MHz
- Flash：64~128KB
- RAM：20KB
- ADC：2×12bit, 10 通道
- 通信接口：USART×3, I2C×2, SPI×2
- 工作电压：2.0~3.6V
- 功耗：~36mA（全速运行）→ 休眠 μA 级

### 4.2 A25 健康监测项圈参数（来自采购说明书）

> 详细参数见 `procurement/A25-健康监测项圈/A25健康检测说明书.docx`

- 设备类型：宠物健康监测项圈
- 主要功能：心率、体温、活动量
- 通信方式：蓝牙 BLE（预计）
- 适配用户：猫/中小型犬

### 4.3 充气项圈参考工程量

| 指标 | 数值 |
|------|------|
| 代码总行数 | ~2000 行 C |
| 已验证外设 | 7 个模块 |
| 工程文件 | Proteus 仿真 (.pdsprj) + Keil MDK (.uvprojx) |
| 项目名称 | 位置判断手环 / 底座 |
