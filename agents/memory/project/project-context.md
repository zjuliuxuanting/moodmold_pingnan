# 项目背景

> 最后更新：2026-05-22

## 产品定位

行为学训练盒上位机软件——用于控制动物行为学实验训练盒的桌面/Web 应用程序。

## 目标用户

- 动物行为学实验人员（生物学背景，非程序员）
- 实验室管理者

## 核心场景

1. 实验人员创建训练方案（定义训练参数、时间表）
2. 启动训练任务，监控训练进度
3. 查看训练数据（动物行为记录、统计）
4. 导出实验报告

## 当前阶段

黑客松 MVP 阶段 —— 快速验证核心功能可行性。
