# 项目背景

> 最后更新：2026-05-22（v0.2 整合版）

## 产品定位

**Moodmold 乡村寄养** — 一个让城市宠物主通过挂牌 + 网页平台，实时看见宠物在乡村的"数字孪生日记"的宠物寄养服务平台。

核心差异化：数字孪生 + 透明监控 + 情绪价值出片。

## 目标用户

| 用户类型 | 描述 | 核心需求 |
|---------|------|---------|
| **宠物主** | 城市养宠人，需要寄养服务 | 看到宠物状态、放心、能出片分享 |
| **托管方** | 乡村民宿/在地寄养点 | 获取客源、提高服务溢价、降低获客成本 |
| **在地合作伙伴** | 提供寄养环境 + 在地信息 | 帮助把控方案在当地的可实施性 |

## 核心场景

1. **托管方**扫描宠物挂牌 → 录入宠物信息 → 绑定数字身份
2. **托管方**每日更新宠物状态（拍照 + 简短文字）→ 自动生成活动时间线
3. **宠物主**扫码或点链接 → 看到宠物的数字主页：照片、活动时间线、每日数字孪生出图
4. 寄养结束时，系统自动生成一张"寄养纪念卡"（可分享/可打印）

## 当前阶段

**黑客松 MVP 阶段（3 天）** — 快速交付可演示的 Demo + 演示视频。
