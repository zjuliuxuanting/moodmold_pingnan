# 项目背景

> 最后更新：2026-05-22（v0.3 战略整合版）

## 产品定位

**Moodmold 乡村寄养** — 一个让城市宠物主通过挂牌 + 网页平台，实时看见宠物在乡村的"数字孪生日记"的宠物寄养服务平台。

**平台角色：我们只规范乡村宠物寄养的模式和标准，不直接参与寄养运营。** 我们的核心是提供工具 + 标准 + 内容能力，让村民/托管方自己去运营寄养服务。

核心差异化：数字孪生 + 透明监控 + 情绪价值出片 + 宠物视角文旅宣传。

## 目标用户

| 用户类型 | 描述 | 核心需求 |
|---------|------|---------|
| **宠物主** | 城市养宠人，需要寄养服务 | 看到宠物状态、放心、能出片分享 |
| **托管方** | 乡村民宿/在地寄养点 | 获取客源、提高服务溢价、降低获客成本 |
| **在地合作伙伴** | 提供寄养环境 + 在地信息 | 帮助把控方案在当地的可实施性 |

## 核心场景

1. **托管方**扫描宠物挂牌 → 录入宠物信息 → 绑定数字身份
2. **托管方**每日更新宠物状态（拍照 + 简短文字）→ 自动生成活动时间线
3. **宠物主**扫码或点链接 → 看到宠物的数字主页：照片、活动时间线、每日数字孪生出图
4. 寄养结束时，系统自动生成一张"寄养纪念卡"（可分享/可打印）

## 当前阶段

**黑客松 MVP 阶段（3 天）** — 快速交付可演示的 Demo + 演示视频。

## 团队

| 成员 | 角色 |
|------|------|
| A | 设计 + 资产 + 方向把控 |
| B | 技术实现 |
| 在地伙伴 | 民宿/寄养资源 + 在地可行性 |

## 关键决策

- ❌ 不做真硬件项圈（3 天不可行），用挂牌 + 托管方打卡模拟
- ✅ 数字孪生 = 本产品的核心体验层
- ✅ Moodle 宠物分身资产完整复用
- ✅ 3 天只交付 1 个托管方 + 1 只宠物的 Demo
- ✅ 平台角色：只规范，不直接运营寄养
- ✅ 以宠物视角做文旅宣传（含「有福」本村猫 IP）

## 战略三大支柱（详见 v0.3）

| 支柱 | 内容 | 面向 |
|------|------|------|
| B1 管理寄养 | 制定规范、村民准入准出、环境标准、硬件评估 | 托管方（村民/民宿） |
| B2 沟通家长 | 数字孪身、实时状态、身份解锁（平南服饰/廊桥合影） | 宠物主 |
| B3 宣传业务 | 宠物视角文旅宣传、数字孪生视频、「有福」猫 IP | 获客/品牌 |

## 村民准入准出机制

**准入：**
- 具备基本宠物饲养环境（独立空间、通风、安全）
- 通过平台环境评估
- 接受平台质量监督

**准出：**
- 多次投诉 → 暂停接单
- 环境不达标且未整改 → 下架
- 主动退出需提前 7 天通知
