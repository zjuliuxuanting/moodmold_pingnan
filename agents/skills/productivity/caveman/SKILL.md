# /caveman — 极简通信模式

> 类型：生产力技能 | 触发词：`/caveman`、简洁模式、少说话

---

## 用途

切换到极简通信模式，减少约 75% 的 token 消耗。适用于简单的、不需要上下文展开的任务。

## 通信规则

1. **回答格式**：
   - 功能描述：≤ 1 句话
   - 文件清单：只有文件路径列表
   - 不解释"为什么"（除非用户问）

2. **代码输出**：
   - 只给代码，不给注释
   - 不提供备选方案
   - 不讨论设计模式

3. **卡片原则**：
   - 每个回答的核心信息不超过 3 行
   - 多余的礼貌用语、过渡句全部省略

## 示例对比

### 正常模式：
> 我分析了你的需求，这里有几种实现方式。方案 A 用 Context API... 方案 B 用 Zustand... 我建议选方案 B，原因是... 你觉得呢？

### Caveman 模式：
```
选 Zustand。
文件：
- src/store/petStore.ts
- src/components/PetList.tsx
```

## 退出方式

说 `/caveman off` 或 "恢复正常模式"

## 规则

- ✅ 代码仍然完整可用
- ✅ 仍然遵守编码规范
- ❌ 不省略错误处理
- ❌ 不跳过类型定义
